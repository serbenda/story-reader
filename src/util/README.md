# util/ · ayudas genéricas

Funciones que **no saben que esto es un juego** y podrían usarse en cualquier web: DOM ([`dom.js`](dom.js)),
azar ([`azar.js`](azar.js)), fechas en hora local ([`fechas.js`](fechas.js)), cuentas
([`numeros.js`](numeros.js)), bus de eventos ([`eventos.js`](eventos.js)) y base64 + gzip
([`base64.js`](base64.js)).

No importa nada. Si una función necesita saber algo del juego (niveles, estado…), no va aquí.
